# Claude Code Crash Course

Learn Claude Code from zero to hero in 2-3 hours. This course takes you from installing the CLI to building automated agent workflows, with short lessons you can read in order.

## Who this is for

Complete beginners. You only need a terminal, a code editor, and basic familiarity with running commands. No prior AI tooling experience is required.

## What is Claude Code

Claude Code is Anthropic's agentic coding tool that runs in your terminal. You describe what you want in plain English, and it reads your codebase, edits files, runs commands, and manages git for you. It is not autocomplete. It is an agent that plans and executes multi-step coding tasks.

## How to use this course

1. Read the lessons in order. Later lessons build on earlier ones.
2. Keep a terminal open and try each command as you read.
3. Use a small practice repository so you can experiment safely. Any project with a few source files works.

## Prerequisites

- A terminal (macOS Terminal, Windows Terminal with WSL, or any Linux shell)
- Node.js 18 or newer, or the native installer (covered in lesson 02)
- A Claude account (Pro, Max, or an Anthropic API key)
